# BurpSuite-CNpatch
适用于[零溢出大佬BS启动器](https://www.bilibili.com/video/BV15jv9esERM/)的汉化补丁，适配v2026.10版本，为保持一致性BS中专有名词保留原文

部分译文来自 MIT 许可的 BurpSuiteCN 并由GPT6.1sol大人完成整合和适配新版

AI Warnings:
本项目有可能存在不稳定、不完善或潜在问题。使用前请自行检查、测试并承担可能风险。/(ㄒoㄒ)/~~

## 使用方法：
[下载](https://github.com/lyteenb/BurpSuite-CNpatch/releases/download/v2026.10/patch_v202610.7z)并解压后复制jre文件夹,粘贴覆盖至启动器中jre文件夹
